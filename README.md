## ✨ Features

### 🤖 Telegram Bot
- **Pairing system** — WhatsApp connect via pair code
- **50+ commands** — Full attack suite
- **User management** — Premium, reseller, free tiers
- **Session handling** — Multi-session support
- **Broadcast system** — Mass messaging
- **Auto-restart** — Crash recovery
- **Admin panel** — Full owner control

### 🌐 Web Dashboard
- **Real-time stats** — Live session/attack counts
- **Attack sender** — Send attacks from browser
- **Session manager** — View connected numbers
- **Premium manager** — Add/remove premium users
- **Protected list** — Block specific numbers
- **Activity logs** — Live log viewer
- **API key auth** — Secure access
- **Mobile responsive** — Works on any device

### 🔒 Security
- **API key auth** — 64-char random keys
- **Rate limiting** — 10 requests per minute
- **Protected numbers** — Block specific targets
- **Session isolation** — Each user's data separate
- **Log rotation** — Auto log cleanup
